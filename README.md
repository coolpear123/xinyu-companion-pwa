# 心语 · AI 伙伴 PWA

这是一个完全独立的个人 PWA 原型，与“夜半不二”系统、代码、数据库和部署环境无关。

## 当前能力

- 可安装到支持 PWA 的手机桌面
- 离线缓存页面和角色素材
- 手机竖屏界面，不建设 PC 客户端或 PC 管理端
- 按住说话、松开发送，包含麦克风权限和录音能力检测
- 支持浏览器语音识别时，可把中文语音转换为本地演示回复
- 待机、聆听、说话、比心动作状态
- 输入文字后触发本地模拟回复和动作
- 使用浏览器自带语音朗读演示“说话”状态

当前版本尚未连接大模型后端或云数据库，也不会保存聊天内容。语音识别仅在手机浏览器支持时用于本地交互验证。

## 本地预览

在项目目录运行：

```powershell
python -m http.server 4173 --directory dist
```

然后访问 `http://127.0.0.1:4173/`。
